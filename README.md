# 課題0403 計算結果のキャスト演算
入力されたintのデータを1.08倍した結果を整数(int)として表示するプログラムを書け．
つまり「入力(int)⇒「×」1.08(double)⇒結果(double)⇒結果をintへ変換⇒結果(int)を表示」
という流れが必要になる。内部での計算はdoubleとして計算し，最後に表示する結果の小数点以下を切り捨てるわけだ。
例えば100を入力すれば100.0*1.08を計算して、答えとして表示するのは108になるはずである．
ここで「結果をintへ変換」するためには、明示的な「キャスト演算」が必要になる。
これは授業第03回のスライドで説明している。
